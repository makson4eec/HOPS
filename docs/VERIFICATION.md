# Проверки рефакторинга Windows

Дата: 11 октября 2026. Windows, Node.js 24.19.0, Next.js 16.4.0. Данные тестов изолированы в `.test-data`; демонстрационные товары не создаются в рабочем хранилище.

- `npm.cmd run lint` и `npm.cmd run typecheck` — успешно.
- `npm.cmd test` — 20 проверок, без пропусков: полные/неполные и устаревшие снимки, allowlist, дубликаты, повреждённый JSON, параллельные записи и три независимых процесса, повторные заказы, изоляция владельцев, резервы и откат, запрет оформления регулируемых товаров, подтверждённая сотрудником привязка бонусов, восстановление зеркала/журнала/копии и повреждения обоих файлов, защита от пустой инициализации поверх потерянных данных.
- `npm.cmd run build` — production-сборка проходит без отдельной СУБД, без предупреждений сборщика.
- Браузерные проверки в Microsoft Edge: 33 сценария страниц, 18+, адаптивности, доступности, регистрации, входа/выхода и отзыва сессий; отдельно прошёл сквозной сценарий JSON-каталога, личного бонусного баланса, самовывоза, отзыва, модерации и админки (всего 34). В сквозном тесте исправлено ожидание серверного добавления товара перед переходом в корзину.
- `npm.cmd run test:runtime` — supervisor запускает production-сервер, отклоняет второй экземпляр, восстанавливает сервер после принудительного завершения и корректно останавливается по запросу. Проверка повторена после добавления идентификации Windows-процесса по PID и времени создания.
- PowerShell-скрипты прошли синтаксический разбор; `git diff --check` проходит.
- `npm.cmd audit --omit=dev` — 0 уязвимостей. В полной проверке остаётся цепочка dev-зависимостей ESLint → fast-glob → micromatch → braces (5 замечаний high, одно исходное advisory); предлагаемое npm исправление требует несовместимого понижения eslint-config-next до 14, поэтому не применялось. Эти зависимости не используются production-сервером.

Не проверялись: реальная задача AtStartup/S4U под сервисной записью магазина, ACL на его носителях, запуск после перезагрузки без входа, конкретный HTTPS-туннель, реальные выгрузки и подтверждения 1С. Установка задачи в этой среде не выполнялась. Команды проверки и порядок настройки — [WINDOWS.md](WINDOWS.md).

Автоматический импорт исходящих заказов в 1С не заявляется: подготовлена папка outgoing, до согласования протокола доступна только проверяемая сотрудником сверка чека/новой выгрузки. Пароли в скрипты и Git не записывались. Git push не выполнялся.
